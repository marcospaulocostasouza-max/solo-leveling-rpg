# Mapa Vivo V2

- Marcadores recalibrados para os números/estrela impressos no mapa horizontal.
- Players e NPCs não aparecem mais diretamente sobre o mapa; aparecem no painel do local.
- Painel de cidade/ilha com imagem individual, guilda dominante, preço, renda e investimentos.
- Valores econômicos são uma economia de RPG inspirada em diferenças reais de mercado, turismo e infraestrutura; não são avaliações imobiliárias oficiais.
- Imagens desta versão são recortes individuais do próprio mapa fornecido, para garantir consistência visual. Podem ser substituídas depois por artes panorâmicas exclusivas sem mudar o código.
