# Mapa Vivo V3

Mudanças desta versão:

- mapa principal ampliado para 3840 × 2560 (próximo de 4K), preservando a arte original;
- mapa passa a ocupar toda a viewport, sem caixa centralizada;
- pan por arraste mais direto no desktop;
- zoom de roda mais suave e menos agressivo;
- limite de zoom aumentado para 5x;
- duplo clique não dispara zoom acidental;
- Gimcheon e Tongyeong permanecem registrados como pontos clicáveis no mapa;
- players, NPCs, guilda dominante, preço e investimentos continuam dentro do painel de cada local, e não desenhados sobre o mapa.

## Executar

```powershell
npm install
npm run dev
```
